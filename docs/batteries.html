案例阶梯 01 → 14

每一级只比上一级多一到三只电池。先跑通当前这级再往下——链路的语义是一层层叠上去的，跳级会分不清是哪层坏了。

01一条线3 电池

Curve → Path Input → Draw Path → Render Output.Cmds Canvas → Render Output.Canvas　　Preview = ✓

失败点：Render Output 的 Canvas 空着就什么都不出。它决定画布尺寸，不是可选项。

02描边与填充5 电池

Stroke Style ─┐ Fill Style ──┴→ Draw Path → Render Output

Stroke · Width2–8 是常用区间；二维线宽是真实像素
Fill · Rulenonzero 常规；自相交图形改用 evenodd

顺序：先画填充再画描边，否则描边会被填充盖掉一半。

03两个图层8 电池

Layer(ink, blend=source-over) ─┐ Layer(glow, blend=screen) ─┴→ 各自接一条 Draw Path → Render Output.Cmds

失败点：Draw Path 的 Layer 端口要接对应 Layer 的输出；不接就是默认层，两个图层等于一个。

04逐笔生长6 电池

Path Input → Draw Progress.Paths → Render Output Timeline → Track → Draw Progress.Progress

失败点：没有 Track 驱动时 Progress 是静态的，看不出"生长"。Timeline 必须接进 Track。

05文字标题6 电池

Text(Text="COLUGO\n2026", Size=160) → Path Input.Curve → Draw Path

要点：文字已转曲线，导出不依赖字体。改字号要重新求解；\n 换行。

06图片与裁剪7 电池

Image(File, Max Size=1024) → Draw Image → Clip → Render Output Curve(圆形) → Path Input → Clip.ClipPath

Clip · Mode1 保留内部 · 2 保留外部（挖空）
Max Size默认 1024；单张 4MB 上限，超了会报警

失败点：裁剪模具用页面坐标，不是图片自己的局部坐标。Path Input 输出的就是页面坐标，直接用。

07笔触海报9 电池

Curve → Path Input → Mark Along Path Brush(形状/尺寸) → Mark Along Path.Brush Track 或 Random → Style Map → Mark Along Path.Style

Spacing相对路径长度的间距，0.02–0.06 密集可见
Style Map把 0–1 映射到尺寸/透明度/颜色，让每笔不同

要点：Mark 输出已经是 DrawCommand，可直接接 Clip 或 Render Output，不用再过 Draw Path。

08对象群8 电池

Curve → Entity Blueprint(数量/分布/速度) → Entity Look(尺寸/颜色/拖尾) → Render Output.Entities

Count200–2000 是安全区间；上万要盯帧率
Trail拖尾是运行时状态，不进 patch，重置会清空

要点：对象走 Entities 端口，不是 Commands。接错端口不会报错，只是什么都不出现。

09表达式驱动7 电池

Runtime Var(uAmp, 1.0) → Runtime Math(Op=mul, B=0.5) → Bind(Property=width) Runtime Time → Runtime Math(Op=sin) → 同上 → Draw Path → Render Output

要点：Bind 之后改值不触发 GH 求解，rev 全程不变。这是"参数在动但定义没变"的判据。

10三维立方体5 电池

Brep → Mesh Input → Draw 3D(Mode=1) → Scene 3D → Render Output.Scene

Draw 3D · Mode1 solid · 2 wireframe · 3 points · 4 normals · 5 unlit
Scene 3D · Camera留空 = 自动取景（按原始包围盒）

失败点：Render Output 有两个几何入口，三维要接 Scene（S3），不是 Commands。

11GPU 变形11 电池

Shader Normal ─────────────────┐ Shader Time → Shader Math(6 sin) → Shader Math(3 mul, B=18) ─┴→ Shader Math(3 mul) → Apply Material.Displace → Scene 3D

振幅 18网格 100 宽时的起点；太小看不出呼吸
Time · Scale0.6 更缓；1 = 真实秒速

失败点：位移是局部空间偏移，不是绝对位置。相机按原始包围盒取景，位移大就出框——把 Canvas 的 Margin 调大。

12条纹着色13 电池

Shader Position → Shader Swizzle(x) → Shader Math(3 mul, B=0.12) → Shader Math(1 add) ← Shader Time → Shader Math(6 sin) → Shader Math(14 remap, B=-1, C=1, D=1) → Shader Mix.Factor Shader Color(深蓝) → Mix.A　　Shader Color(橙) → Mix.B　　Mix → Apply Material.Colour

remap 的四个输入：A=输入，B=in0，C=in1，D=out1，out0 固定 0。sin 的 −1…1 变 0…1 就要 B=−1, C=1, D=1。

13二维贴三维14 电池

Draw Path(二维线稿) → 二维层 ──────────────┐ Shader Canvas(Space=2 Screen) → Apply Material.Colour → Scene 3D(Transparent ✓) → Render Output（二维与三维同帧可见）

失败点：Screen 模式按屏幕坐标采样，二维内容要画在物体所在的屏幕中央。画在角落会贴出一片纯色——那是采样到空白，不是纹理坏了。

14完整作品18+ 电池

二维：Draw Path / Mark Along Path / Text → 图层 三维：Mesh Input → Draw 3D → Apply Material(Colour + Displace) → Scene 3D(Transparent ✓) → Post FX(Bloom=0.9, Threshold=0.45) → Render Output

Bloom0.5–1.5 可用；画面本就很亮时把 Threshold 推到 0.6+
Transparent✓ 才能二维三维同帧；关掉则三维背景盖住二维
导出PNG / SVG / 序列 / 视频 / 独立 HTML，和后处理一致

调试顺序：先关 Bloom、关 Displace、关透明，只留颜色——画面正确后逐项打开。同时开三个新功能出问题，分不清是谁。
