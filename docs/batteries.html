三条最小链路 START HERE

第一次打开先跑这三条。每条都能在一分钟内看到画面，跑通再往下看。

① 静态二维

Curve → Path Input → Draw Path → Render Output.Cmds Canvas → Render Output.Canvas　　Render Output.Preview = ✓

失败点：Render Output 的 Canvas 空着就什么都不出。它决定画布尺寸，不是可选项。

② 三维 + GPU 位移

Surface / Mesh → Mesh Input → Draw 3D(Mode=5) → Apply Material → Scene 3D → Render Output.Scene ↑ Displace Shader Normal → Shader Math(Op=3 mul) ← Shader Math(Op=6 sin) ← Shader Time

失败点：位移幅度按 Rhino 世界单位算。网格 100 宽时乘 20 才看得出呼吸；乘 1 几乎不可见。相机按原始包围盒取景，位移太大就出框。

③ 二维线稿贴到三维

2D 图层 → Draw Path ─┐ Shader Canvas(Space=2 Screen) → Apply Material.Colour → Scene 3D(Transparent ✓) → Post FX → Render Output

失败点：Screen 模式按屏幕坐标采样，二维内容要画在立方体所在的屏幕中央区域才看得见。画在角落会贴出一片纯色——那是"采样到空白"，不是纹理坏了。

接线配方：三个作品骨架 RECIPES

不是罗列端口，是能直接照搭的结构。每条的参数都是实测过的起点值。

GPU 呼吸雕塑

Mesh Input → Draw 3D(Mode=5, Glow=0.6) → Apply Material → Scene 3D(Transparent ✓) → Post FX(Bloom=0.9) → Render Output Colour ← Shader Mix(A=深蓝, B=橙, Factor=条纹) Displace ← Shader Math(Op=3) ← A: Shader Normal ／ B: Shader Math(Op=3, B=18) ← Shader Math(Op=6 sin) ← Shader Time(Scale=0.6)
参数起点值作用
Draw 3D · Mode5 (unlit)忽略光照，颜色/位移最干净
sin 的振幅18太小看不出呼吸，太大出框
Shader Time · Scale0.61 = 真实秒速，0.6 更缓
Post FX · Threshold0.45亮部才开始发光；画面本就亮就往上推

参数化条纹墙

Shader Position → Shader Swizzle(Channel=1 x) → Shader Math(Op=3, B=0.12) → Shader Math(Op=1 add) ← Shader Time → Shader Math(Op=6 sin) → Shader Math(Op=14 remap, B=-1, C=1, D=1) → Shader Mix.Factor Shader Color(深蓝) → Mix.A　　Shader Color(橙) → Mix.B　　Mix → Apply Material.Colour

remap 的四个输入：A=输入，B=in0，C=in1，D=out1，out0 固定 0。所以 sin 的 −1…1 变 0…1 要 B=−1, C=1, D=1。

线稿投影体

Draw Path(二维线稿) → 二维层 Shader Canvas(Space=2) → Apply Material.Colour → Draw 3D.Cmds Scene 3D(Transparent ✓, Background 随便设) → Render Output 可选：同时把 Post FX(Bloom=0.6) 串在 Scene 3D 之后

为什么会透出：Transparent 打开后三维不清背景，二维层从后面透出来。三处联动（canvas alpha / clearAlpha / 后处理 alpha）缺一个就不透。

Shader 11 只

一类新的值：ShaderExpr。它不是数字，是"一段将在 GPU 上求值的节点图"。每只电池产出一小段，连接时自动合并。端口可以直接接数字，会变成常量。

Shader Position SPos

in Space(1 local · 2 world) ／ out Shader

顶点位置，vec3。取分量要接 Shader Swizzle。

Shader Normal SNrm

in Space ／ out Shader

表面法线，vec3。做"沿法线膨胀"就靠它。

Shader UV SUV

out Shader

纹理坐标，vec2。首版只 UV0；网格没有 UV 属性时是常量。

Shader Uniform SUni

in Name, Value ／ out Shader

命名浮点参数。改值不重建材质、不重编译——只发一条 151 字节的增量。首版只 float。

Shader Math SM

in Op, A, B, C, D ／ out Shader

20 个算子一只电池。常用：3 mul · 6 sin · 14 remap · 16 clamp · 17 step。输出类型跟 A 走。

Shader Mix SMix

in A, B, Factor ／ out Shader

线性插值。A/B 通常是颜色，Factor 是 float 图。

Shader Color SCol

in Mode(1 RGB · 2 HSL), R/H, G/S, B/L ／ out Shader

颜色常量。HSL 在 GH 侧就算成 RGB，运行时只认 vec3。

Shader Swizzle SSwz

in A, Channel(1 x · 2 y · 3 z) ／ out Shader

从 vec3 里取一个分量出来。没有它，Position 拿到手也用不了。

Shader Time STime

in Scale, Offset ／ out Shader

作品时钟，每帧更新。不能用 Runtime Time 代替——那是 JS 层表达式，与 GPU 层不是一个类型。

Shader Vector SVec

in X, Y, Z ／ out Shader

三个标量拼成 vec3，缺省补 0。构造方向、位移向量用。

Shader Canvas SCan

in Space(1 UV · 2 Screen) ／ out Shader

把二维画布当纹理。默认 Screen：多数网格没有 UV，UV 模式会贴成一片纯色。

Apply Material ApplyMat

in Commands, Colour, Displace ／ out Commands

把图挂到三维命令上。Colour 要 vec3，Displace 是局部空间偏移（不是绝对位置）。两个都不接就原样透传。

两个颜色槽都要 v3。接错类型不会崩，但画面会是一片纯色——比报错更难查。Apply Material 会在电池上明确报"输出是 f，颜色槽要 v3"。

三维 7 只

Mesh Input MeshIn

in Geometry, Density ／ out Meshes, Info

Rhino 几何 → 三角网格，世界坐标。Brep 用默认网格参数。

Transform 3D Xform3D

in Meshes, Xform(3) ／ out Meshes

在三维链路里做变换。动画时长可参数化。

Draw 3D Draw3D

in Meshes, Mode, Colour, Size, Glow, Opacity ／ out Commands

Mode：1 solid · 2 wireframe · 3 points · 4 normals · 5 unlit。1 和 5 吃颜色，4 忽略颜色。

Camera 3D Cam3D

in 5 ／ out Camera

显式相机。留空则自动取景（按原始包围盒）。

Scene 3D Scene3D

in Commands, Camera, Background, Lights, Transparent ／ out Scene

收集命令与相机。Transparent ✓ 时清空背景，二维层从后面透出来（合成用）。

Post FX FX

in Scene, Bloom, Threshold, Radius ／ out Scene

Bloom 辉光。Bloom=0 关闭（0.5–1.5 可用）；Threshold 是发光门槛，画面亮就往上推；Radius 是弥散范围。

Point 3D / Curve 3D Pt3D · Crv3D

in 1 / 2 ／ out 单值

点与曲线的三维输入，用于点云线框一类的构造。

3D 的点大小与线宽调不了。WGSL 的 point-list / line-list 固定 1 像素，`Size` 参数无效。 要粗细请用几何代替：曲线 Pipe 成圆柱、点 Sphere 成小球，就变成 mesh，粗细完全可控。

二维：画布与输出 14 只

Canvas

in 4（尺寸 / 背景 / 边距…） ／ out Canvas

画布定义。Render Output 必须接它，否则没有尺寸。

Render Output Render

in Canvas, Commands, Entities, Enabled, Preview, Scene ／ out Status, Url

唯一的出口。Preview ✓ 弹内嵌窗口；Url 可以在外部浏览器打开。

Path Input PathIn

in Curve, Page W, Page H, Margin ／ out Paths, Info

Rhino 曲线 → 页面坐标路径。相机在这里一次框定，不随几何旋转重算。

Draw Path DrawPath

in 10（路径 / 图层 / 顺序 / 描边 / 填充…） ／ out Commands

核心绘制。10 个输入是有意为之，不要拆。

Draw Progress Progress

in 3 ／ out Commands

按进度逐笔生长，做"画出来"的过程。

Draw Points DrawPts

in 4 ／ out Commands

二维点阵。这里的点可以调大小（Canvas 2D 没有 WebGPU 那条限制）。

Stroke Style / Fill Style Stroke · Fill

in 6 / 4 ／ out 样式

描边与填充。二维线宽是真实像素宽度。

Layer Layer

in 6 ／ out Layer

图层与合成模式（blend 真实合成）。

Project to 2D Proj2D

in 6 ／ out Paths, Info

把三维几何投影到页面坐标。

Runtime Info Info

out 6（帧率 / 对象数 / 耗时…）

自检面板。调参数时先看它，别看画面猜。

笔触系统 3 只

笔触是"沿路径盖印章"。它比普通描边多了每笔的尺寸/角度/颜色，是二维层表达力最强的一组。

Brush Brush

in 5 ／ out Brush, Info

印章的定义：形状、尺寸、软硬。

Mark Along Path Marks

in 6 ／ out Commands, Info

沿路径按间距盖印章。输出直接是 DrawCommand，可接 Clip / Render Output。

Style Map StyleMap

in 5 ／ out Style, Info

把 0–1 的值映射到尺寸/不透明度/颜色，让每笔不一样。

文字 · 图片 · 裁剪 4 只

Text Text

in Text, Font, Size, Bold, Italic, Tolerance ／ out Curves, Info

文字转成曲线，运行时零字体依赖。改字号 = 重新求解。

Image Image

in File, Max Size ／ out Image, Info

读图 → 等比降采样 → data URL。同路径+同尺寸只读一次盘。

Draw Image DrawImg

in Image, Layer, Order, X, Y, Opacity ／ out Commands

只负责放哪、多透明；缩放归变换。

Clip Clip

in Commands, Clip Path, Mode(1 内 · 2 外) ／ out Commands

指令级裁剪。模具用页面坐标，在指令变换之前落剪。一个指令只能有一个 clip。

对象与动画 6 只

Entity Blueprint Blueprint

in 5 ／ out Blueprint

动态对象的分布与运动定义。确定性分布，不掷骰子。

Entity Look Look

in 8 ／ out Entities

外观：尺寸、颜色、拖尾、淡出。

Timeline Timeline

in 3 ／ out Timeline

全局时间轴：播放 / 暂停 / 循环。

Track Track

in 6 ／ out Track

把任意参数绑到时间轴上，带缓动。

Transform Xform

in 2 ／ out Command

二维变换。世界里的旋转会做一次相机共轭（已数值验证）。

Morph Morph

in 2 ／ out Commands

两条路径之间插值。点序要一致，否则会拧。

运行时表达式 8 只

这一组在浏览器里每帧求值，不触发 GH 求解。和 Shader 是两层：这层在 JS，Shader 在 GPU。

Runtime Var Var

in Name, Initial ／ out Expr

运行时变量。事件可以改它，表达式读它。

Runtime Time Time

in Scale, Offset ／ out Expr

浏览器时钟（JS 层）。不能接 ShaderExpr——类型不同，要 Shader 层的时间用 Shader Time。

Runtime DT DT

out Expr

帧步长的唯一来源。别手填 1/60——步长一改，所有作品速度静默翻倍。

Runtime Math Math

in Op, A, B ／ out Expr

含 gt / lt / select / noise / remap 等算子。

Runtime Remap / Select Remap · Select

in 3 ／ out Expr

区间映射与二选一。Select 就是条件分支。

Bind Bind

in Command, Property, Expr ／ out Command

把表达式绑到指令属性上。改值不重发整个定义。

Event Rule Rule

in 6 ／ out Rules

事件 → 写变量（set / toggle / add）。

Interaction / Event Trigger Interaction · Trigger

in 0 / 5 ／ out Pointer 等 5 / Events

指针坐标是画布坐标（左上原点、Y 向下），不是 Rhino 世界坐标。

状态与行为 4 只

让对象自己读写状态、繁殖、销毁。程序在 GH 侧编译一次，运行时按帧推进。

Read State ReadSt

in 2 ／ out 2

读对象自己的状态（位置 / 年龄 / 代数 / 序号）。

Write State WriteSt

in 5 ／ out 2

写谁谁归你：写了 x/y 就不再沿曲线跑。这是自定义行为的开关。

Spawn Spawn

in 6 ／ out 2

繁殖子代。上升沿触发，不是每帧——否则一秒就爆到上限。

Destroy Destroy

in 3 ／ out 2

到龄销毁，可留残影。残影是运行时状态，不进 patch。

随机与信号 5 只

Random Rand

out 2

确定性随机。同种子同结果，可复现。

Noise 1D / 2D / 3D Noise

in 1 / 2 / 3 ／ out 2

Perlin 噪声。连续、可导，做流体感与有机分布。

Signal to Float Sig2F

in 1 ／ out 1

音频信号 → 数值。
